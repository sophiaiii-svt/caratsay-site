克拉SAY 背景音乐（BGM）说明
============================

现在 BGM 有两套来源，推荐用第一种。


一、云端音乐库（推荐，默认方式）
--------------------------------
曲目存在 Supabase Storage，不占仓库体积，所有访客可见。

  播放列表：bgm/playlist.json
  音频文件：bgm/audio/*.m4a

在页面上管理：克拉SAY 板块 → 点「BGM 关」打开 → 点右侧曲目气泡展开 →
「添加曲目」，可上传本地音频或粘贴直链。上传后所有人立即能听到。

已预置的三首（站长上传，访客无法删除）：

  US again              → 网格视图
  青春赞歌 (Cheers)      → 回忆册视图
  Circle                → 放映视图

需要重新灌入这三首，或改动曲目信息，跑：

  node scripts/seed-bgm.mjs


二、放到本目录（备用方式）
--------------------------
把音频按下面的文件名放进 public/audio/，页面会自动探测到并加进列表。
注意探测是按 Content-Type 判断的，不是按状态码——静态托管的 SPA fallback
会把缺失文件也返回 200，所以别指望删掉文件还能蒙混过关。

  文件名                      对应视图 / 曲目
  ------------------------------------------------------------
  bgm-wang-ge-gou.m4a        克拉SAY 整体主题曲 · 《玩个够》
  bgm-us-again.m4a           网格视图 · 《US again》
  bgm-cheers.m4a             回忆册视图 · 《青春赞歌 (Cheers)》
  bgm-circle.m4a             放映视图 · 《Circle》

同一首歌若云端也有，按标题去重，只会出现一次。


注意
----
- 这些都是 SEVENTEEN 的版权音乐，请用你合法拥有的音频，勿对外分发。
- 格式支持 mp3 / m4a / wav / ogg。m4a 的 MIME 是 audio/mp4，
  别写成 audio/mpeg，否则部分浏览器拒绝播放。
- 外链必须是**音频文件直链**（返回 audio 类型的 Content-Type）。
  网易云、YouTube 的页面链接不能用，那是网页不是音频。
- 曲目可绑定「场景」，切换网格 / 回忆册 / 放映时会自动换到对应曲目；
  手动选过歌后会暂停跟随，直到再次切换视图。
